# WebP Converter

Скрипт для пакетной конвертации изображений в WebP с сохранением структуры папок.

Берёт все картинки из указанной папки (включая подпапки), конвертирует их в `.webp`
и складывает в другую папку. Выходная папка создаётся автоматически, если её нет.

## Требования

- Нужна Node.js версии 18 или выше. Проверить через cmd:

win + r - откроется "выполнить" ввести cmd или просто открыть терминал и выполнить

```bash
node -v
```

Если результата вывода в терминале нет — ставится с https://nodejs.org (LTS-версия, кнопка “Download”). Больше ничего вручную ставить не надо, sharp подтянет свои бинарники сам при npm install.

Всё остальное (включая бинарники для конвертации) ставится одной командой.

## Установка

```bash
git clone https://github.com/JohnyBlacksad/webp-converter
cd webp-converter
npm install
```

## Использование

Базовый синтаксис:

```bash
node to-webp.js <входная_папка> <выходная_папка> [опции]
```
Пример в cmd или bash c перезаписью существующих webp в папке (если одинаковый нейминг)

```bash
node to-webp.js "C:\Users\Ivan\Pictures\raw" "C:\Users\Ivan\Pictures\webp" --quality 85 --overwrite
````

### Примеры

Конвертировать всё из `./images` в `./webp` с качеством по умолчанию (90):

```bash
node to-webp.js ./images ./webp
```

Своё качество (бери это если не хочешь разбираться):

```bash
node to-webp.js ./images ./webp --quality 85
```

Без потерь (для скриншотов, иконок, UI-графики):

```bash
node to-webp.js ./images ./webp --lossless
```

Перезаписать уже существующие `.webp`:

```bash
node to-webp.js ./images ./webp --overwrite
```

Больше параллельных задач (по умолчанию 4):

```bash
node to-webp.js ./images ./webp --concurrency 8
```

Тихий режим — только итоговая статистика:

```bash
node to-webp.js ./images ./webp --quiet
```

## Опции

| Опция              | Описание                                                        | По умолчанию |
| ------------------ | --------------------------------------------------------------- | ------------ |
| `--quality N`      | Качество 1–100. Игнорируется при `--lossless`.                  | `90`         |
| `--lossless`       | Сжатие без потерь. Хорошо для скриншотов и графики.             | выкл.        |
| `--overwrite`      | Перезаписывать существующие `.webp`.                            | выкл.        |
| `--concurrency N`  | Сколько файлов обрабатывать параллельно.                        | `4`          |
| `--quiet`          | Не выводить построчный лог, только итог.                        | выкл.        |
| `--help`, `-h`     | Показать справку.                                               | —            |

## Поддерживаемые форматы

На входе: `jpg`, `jpeg`, `png`, `bmp`, `tif`, `tiff`, `gif`, `avif`, `svg`.
Анимированные GIF остаются анимированными.

На выходе — всегда `.webp`.

## Как это работает

1. Проверяет, что входная папка существует.
2. Создаёт выходную папку, если её нет.
3. Рекурсивно обходит вход и собирает все поддерживаемые изображения.
4. Сохраняет структуру подпапок: `images/a/b/c.png` → `webp/a/b/c.webp`.
5. Конвертирует файлы параллельно (пул воркеров, размер — `--concurrency`).
6. Не трогает уже существующие `.webp`, если не передан `--overwrite`.
7. Ошибка на одном файле не останавливает процесс — скрипт логирует её и идёт дальше.
8. В конце выводит статистику: успешно / пропущено / ошибок / время.

## Качество

- `--quality 80 - 85` с потерями, как JPEG. Для **фотографий** это правильный режим. 90 — визуально почти без потерь, 80 — заметно легче файл. Используй 85 - стандарт.

Если не знаешь, что за картинки — начните с `--quality 85`. Для скриншотов и графики попробуйте `--lossless`.

## Частые проблемы

**`Error: Cannot find module 'sharp'`**
Не выполнен `npm install`. Запусти его в папке проекта.
Перейди в папку проекта и запусти терминал оттуда, и из терминала выполняй конвертацию.

**`npm install` падает на Windows**
Почти всегда из-за старой версии Node. Нужна 18+. Обнови Node.

**Медленно на большом количестве файлов**
Подними `--concurrency` до `8` или `16`, если у CPU достаточно ядер.
